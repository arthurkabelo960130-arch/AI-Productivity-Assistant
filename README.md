# AI-Productivity-Assistant

**Google AI Essentials Capstone Project 2026**
AI-powered toolkit to help business administrators and job seekers automate daily tasks using prompt engineering. Built for the CAPACITI Digital Career Accelerator programme.

## 🎯 Problem It Solves
Admin professionals and job seekers waste 2+ hours daily on repetitive writing tasks: emails, meeting summaries, and task planning. This project uses AI to cut that to under 10 minutes.

## ✨ Core Features
1. **Smart Email Generator** - Write professional emails in 30 seconds
2. **Meeting Notes Summarizer** - Convert 1-hour transcripts to action items
3. **AI Task Planner** - Turn goals into 5-day Eisenhower Matrix schedules

All prompts use the Persona → Task → Context → Format structure.

## 📁 What's In This Repo
- `prompts.md` - Copy-paste prompts for all 3 features with usage guides
- `README.md` - You are here

## 🚀 How To Use
1. Open `prompts.md`
2. Choose a feature and copy its prompt
3. Paste into Gemini or ChatGPT
4. Replace [brackets] with your info
5. Get results in 30 seconds

## 🛠️ Tools Used
- **Google Gemini** - Primary AI for email and planning prompts
- **ChatGPT** - Alternative AI for meeting summaries
- **GitHub** - Documentation and version control
